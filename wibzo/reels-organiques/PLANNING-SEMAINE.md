# Planning organique — semaine de test (14.10 → 19.10.2026)

Préparé le 12.10.2026. 3 Reels/jour (12:00 · 18:00 · 20:30) + 1 carrousel tous les 2 jours (09:00).
But : tester un maximum d'**accroches différentes** pour trouver ce qui retient (durée de visionnage, partages,
enregistrements, abonnés) → les 2–3 meilleures passent en pub Meta après la semaine.
Règles : tutoiement, contenu pour tout le monde (pas que les patrons), sans visage, musique originale,
commerces 100 % fictifs marqués « Exemple fictif », aucune statistique inventée.
Fabrication : même pipeline que `reels.html` (voix seulement si ElevenLabs est débloqué, sinon texte à l'écran + bruitages).

## 7 familles d'accroches (on en teste plusieurs par jour)
| Code | Famille | Pourquoi ça peut marcher |
|---|---|---|
| SPD | Speedrun « site de X en 15 s » (série : les commentaires choisissent le commerce suivant) | Satisfaisant, crée une série → abonnement |
| AVA | Avant / après | Transformation = on regarde jusqu'à la fin |
| LIS | Liste « 3 raisons / 3 erreurs » | Utile → enregistrements |
| NOT | « Note ce site sur 10 » | Commentaires |
| POV | POV humour (« POV : tu cherches le numéro d'un resto sur son site… ») | Relatable → partages |
| AB  | « A ou B ? Lequel tu choisis ? » | Interaction rapide, commentaires |
| DEF | Défi / mystère (« Ce site cache un détail qui fait fuir les clients. Tu le vois ? ») | Curiosité → revisionnage |
