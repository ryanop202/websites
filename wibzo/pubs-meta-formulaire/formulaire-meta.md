# Formulaire Meta Wibzo

## Avant de commencer
- Page Facebook Wibzo + compte publicitaire Meta
- Page protection des données en ligne sur wibzo.ch (Meta l'exige pour publier)

## Créer le formulaire (adsmanager.facebook.com)
1. Créer → objectif **Prospects** (Leads)
2. Ensemble de publicités → lieu de conversion : **Formulaires instantanés** → page Wibzo
3. Publicité → section « Formulaire instantané » → **Créer un formulaire**
4. Type : **Intention plus élevée** (Higher intent)
5. Intro, questions, confidentialité, écran de fin (textes ci-dessous)
6. Publier le formulaire, ne pas encore lancer la campagne
7. Tester avec le **Lead Ads Testing Tool** de Meta

⚠️ Une fois la pub active, le formulaire ne peut plus être modifié (il faut le dupliquer).
⚠️ Meta garde les prospects ~90 jours : exporter chaque soir (Meta Business Suite → Centre des prospects) vers suivi-wibzo.xlsx.
Les noms de menus peuvent changer selon la version de Meta.

## Textes

**Intro**
- Titre : Votre maquette de site gratuite en 24h
- Texte : On crée la maquette de votre site avec vos vraies infos. Elle vous plaît ? On la met en ligne. Sinon, vous ne payez rien.

**Questions**
1. Nom complet (prérempli)
2. Numéro de téléphone (prérempli)
3. Nom de votre commerce (texte court)
4. Votre métier (choix) : Coiffeur / Barbier · Garage · Artisan · Restaurant / Café · Beauté / Bien-être · Autre
5. Ville (texte court)

**Phrase sous les questions**
Nous vous enverrons votre maquette par WhatsApp au numéro indiqué.

**Protection des données** : lien vers la page de wibzo.ch

**Écran de fin**
- Titre : C'est noté !
- Texte : Vous recevez votre maquette sur WhatsApp dans les 24h. Ryan, Wibzo
- Bouton : Voir wibzo.ch
