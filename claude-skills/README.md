# Skills Claude Code

Copie des skills installés dans `~/.claude/skills` (sans `synced/`, qui se synchronise tout seul avec le compte claude.ai).

Installer sur un autre PC (Git Bash) :

```
mkdir -p ~/.claude/skills && cp -r claude-skills/* ~/.claude/skills/ && rm ~/.claude/skills/README.md
```

Puis redémarrer Claude Code.
